    key "matrixArpeggiator"
    is api.TargetType.NoteTrackPlayer, api.TargetType.PatternTrackPlayer

    The MatrixArpeggiator is a pattern-based arpeggiator that generates notes based on:

    • the currently incoming notes (e.g. from a note track)
    • the arpeggiation parameters of the currently playing pattern
